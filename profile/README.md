## IQ2i

We build web applications and open-source tooling, mostly in PHP and Symfony.

Some of what we maintain publicly:

- **[vigie-bundle](https://github.com/IQ2i/vigie-bundle)** — keep an eye on your Symfony project's dependencies.
- **[data-importer](https://github.com/IQ2i/data-importer)** — import data from anywhere into anything.
- **[storia-bundle](https://github.com/IQ2i/storia-bundle)** — a storybook for your Symfony components.
- **[tailwind-cs-fixer](https://github.com/IQ2i/tailwind-cs-fixer)** — sort Tailwind classes in your templates.
- **[messenger-import-bundle](https://github.com/IQ2i/messenger-import-bundle)** — import files through Symfony Messenger.
- **[typescript-types-bundle](https://github.com/IQ2i/typescript-types-bundle)** — generate TypeScript types from your PHP classes.

The shared CI workflows behind these repositories live in [this one](https://github.com/IQ2i/.github).
